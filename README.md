# Financial News Sentiment and Short-Horizon Equity Prediction

This repository contains the code for the project:

**Financial News Sentiment and Short-Horizon Equity Prediction: A Diagnostic Study Using FinBERT**

The project investigates whether FinBERT-scored public financial news adds predictive value for short-horizon equity returns beyond price-based features. The main study covers AAPL, AMZN, MSFT, NVDA, and TSLA from 2020 to 2024, with SPY used as the market benchmark for excess-return targets.

## What Is Included

- `scripts/`: data collection, feature engineering, FinBERT scoring, model experiments, and final evidence-pack generation.
- `notebooks/`: lightweight notebooks used to run or document stages of the pipeline.
- `requirements-modeling.txt`: core modelling dependencies.
- `requirements-finbert.txt`: dependencies for FinBERT scoring.

The raw external inputs and the project-generated data artifacts are intentionally not committed. Some data is downloaded from external providers, while other files are created by this project, especially the FinBERT-scored article tables, daily sentiment aggregates, engineered features, modelling datasets, predictions, and result tables. These generated files are large and reproducible from the scripts.

## Project-Generated Data

The following files are created by this project rather than downloaded as finished datasets:

- `finbert_article_scores*.csv`: article-level FinBERT positive, negative, neutral probabilities, predicted labels, and sentiment scores.
- `news_target_tickers_finbert_scored*.csv`: source news joined with the project-generated FinBERT scores.
- `daily_finbert_sentiment_features*.csv`: daily ticker-level sentiment aggregates.
- `daily_news_quality_features*.csv`: duplicate-aware, source-weighted, high-confidence, and event/topic news features.
- `model_dataset_finbert*.csv` and `model_dataset_finbert_quality_complete*.csv`: final ticker-day modelling tables built from prices, news, FinBERT scores, market context, and engineered features.
- `model_dataset_finbert_social_attention*.csv`: project-generated modelling tables that join YoloStocks Reddit mention counts to the price/news dataset.
- `social_attention*.csv` outputs: experiment results and coverage summaries from the Reddit attention branch.
- `outputs/tables/*.csv`: experiment summaries, predictions, validation checks, and report tables.

These are research outputs generated by the pipeline. They are excluded from Git because of size and reproducibility, not because they are all third-party downloads.

## Setup

From this `code/` directory:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-modeling.txt
python -m pip install -r requirements-finbert.txt
```

Some later experiment scripts use optional packages that are not required for the baseline pipeline:

```powershell
python -m pip install matplotlib lightgbm xgboost catboost yfinance
```

Set the Polygon API key outside the repository:

```powershell
$env:POLYGON_API_KEY = "your_polygon_key_here"
```

Do not commit API keys or `.env` files.

## Reproducing the Main Data Branch

The exact run can take a long time because it downloads news, fetches prices, and scores articles with FinBERT.

Fetch ticker-specific Polygon news:

```powershell
python scripts/fetch_polygon_news.py --project-root . --tickers AAPL MSFT TSLA AMZN NVDA --start-date 2020-01-01 --end-date 2025-01-01 --output-name polygon_news_2020_2024.json --summary-name polygon_news_2020_2024_fetch_summary.csv --checkpoint-each-window
```

Fetch Google market-context news:

```powershell
python scripts/fetch_google_news_rss.py --project-root . --market-context --start-date 2020-01-01 --end-date 2025-01-01 --window-days 31 --output-name google_news_rss_market_context_2020_2024.json --summary-name google_news_rss_market_context_2020_2024_summary.csv --checkpoint-each-request
```

Fetch Polygon market-proxy news and combine it with Google market-context news:

```powershell
python scripts/fetch_polygon_news.py --project-root . --tickers SPY QQQ DIA IWM --start-date 2020-01-01 --end-date 2025-01-01 --output-name polygon_market_proxy_news_2020_2024.json --summary-name polygon_market_proxy_news_2020_2024_fetch_summary.csv --checkpoint-each-window
python scripts/build_polygon_market_proxy_context.py --project-root .
```

Build the base price/news dataset:

```powershell
python scripts/run_data_preparation.py --project-root . --news-path data/raw/polygon_news_2020_2024.json --market-news-path data/raw/combined_market_context_polygon_proxy_google_2020_2024.json --start-date 2020-01-01 --end-date 2025-01-01 --output-suffix 2020_2024_polygon_proxy_market --use-default-reliable-publishers --min-text-chars 40
```

Score articles with FinBERT and build daily sentiment features:

```powershell
python scripts/run_finbert_sentiment_pipeline.py --project-root . --news-input-name news_target_tickers_2020_2024_polygon_proxy_market.csv --price-features-input-name price_features_2020_2024_polygon_proxy_market.csv --output-suffix 2020_2024_polygon_proxy_market --batch-size 16
```

Build the final cleaned, quality-feature dataset:

```powershell
python scripts/build_cleaned_news_model_dataset.py --project-root . --scored-news-name news_target_tickers_finbert_scored_2020_2024_polygon_proxy_market.csv --price-features-name price_features_2020_2024_polygon_proxy_market.csv --output-suffix 2020_2024_polygon_proxy_market_cleaned_news
```

## Running Experiments

Baseline price/news classification:

```powershell
python scripts/run_modelling_baselines.py --project-root . --dataset-name model_dataset_finbert_complete_2020_2024_polygon_proxy_market.csv
```

Final target formulation screen:

```powershell
python scripts/run_target_formulation_ultra_screen.py --project-root . --dataset-name model_dataset_finbert_quality_complete_2020_2024_polygon_proxy_market_cleaned_news.csv --scored-news-name news_target_tickers_finbert_scored_2020_2024_polygon_proxy_market_cleaned_news.csv --output-suffix 2020_2024_polygon_proxy_market_cleaned_news
```

Recent-validation confidence check:

```powershell
python scripts/run_validation_confidence_target_screen.py --project-root . --dataset-name model_dataset_finbert_quality_complete_2020_2024_polygon_proxy_market_cleaned_news.csv --scored-news-name news_target_tickers_finbert_scored_2020_2024_polygon_proxy_market_cleaned_news.csv --output-suffix 2020_2024_polygon_proxy_market_cleaned_news
```

Portable regression experiments:

```powershell
python scripts/run_portable_regression_experiments.py --project-root .
```

Supplementary Reddit attention experiment:

```powershell
python scripts/run_social_attention_experiment.py --project-root .
```
